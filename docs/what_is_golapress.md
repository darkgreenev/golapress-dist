# What Is goLaPress?

goLaPress is a Go-based content management system built around a familiar WordPress-style admin experience, but with a smaller, more bounded core.

It is designed for operators and site teams who want:

- a single Go binary for the app runtime
- a predictable admin UI for day-to-day site work
- themes and plugins with explicit contracts
- backups, restore flows, and operational tools built in

At a high level, goLaPress is made for:

- posts and pages
- media management
- themes and theme content
- plugins and plugin-controlled admin surfaces
- AI-assisted admin workflows when enabled
- operator tools like runtime, backups, and updates

What it is not:

- not a generic framework for arbitrary app development
- not a plugin marketplace platform
- not an unrestricted runtime for arbitrary PHP-style extensions
- not a shell replacement or raw database admin tool
