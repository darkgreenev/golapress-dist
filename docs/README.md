# Public User Docs

Files in this folder are public distribution docs.

If you are new to goLaPress, start with the overview pages below. If you are building on the platform, move on to the technical references and implementation guides.

Rules:

- anything here is mirrored into `golapress-dist/docs/`
- anything here is included in released binary bundles under `docs/`
- keep internal planning, architecture, and team workflow notes in `docs/`, not here
- plugin-specific public docs live in each plugin repo under `user-docs/` and are published to `golapress-dist/plugins-user-docs/<plugin-id>/`
- the public plugin docs tree includes a generated landing page at `plugins-user-docs/index.html`
